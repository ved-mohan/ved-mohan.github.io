A Fair OR–ML Framework for Resource Substitution in Large-Scale Networks

Ved Mohan, El Mehdi Er Raqabi, Pascal Van Hentenryck · Transportation Science, major revision

Freight moves unevenly, so equipment piles up in some places and runs short in others. We rebalance a nationwide logistics network by swapping equipment on trips that are already scheduled, use machine learning to prune the model so it solves at full scale, and add a fairness weight so the resulting changes don’t all land on one scheduler.

Democratizing Large-Scale Re-Optimization with LLM-Guided Model Patches

Tinghan Ye, Arnaud Deza, Ved Mohan, El Mehdi Er Raqabi, Pascal Van Hentenryck · NeurIPS 2026 Workshop on ML×OR

Deployed optimization models drift out of date as rules and conditions change. ReOpt-LLM lets a planner ask for a change in plain language; an LLM turns the request into small, auditable patches to the model, picks a re-optimization technique, and re-solves.
